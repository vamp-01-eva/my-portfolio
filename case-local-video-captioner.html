project overview

The final stage of the pipeline. It takes an edited local video, finds its subtitle track, and burns styled captions onto it with clip_helper.py, keeping the source resolution.

The captioner runs after the clips have been edited. A form supplies the local video path, an optional subtitle path, and the caption style. The workflow prepares the job, calls clip_helper.py to burn the captions, parses the result, and builds a report.

Subtitle lookup checks an explicit path first, then a matching .srt or .vtt beside the video, then an embedded text track. The output keeps the source resolution and is written to a captions folder with the ASS and JSON caption files.

The project is a working local prototype. It does not download, cut, or reframe the video; it only adds captions.

The clipper and reclipper keep clips caption-free; the captioner adds captions after editing.

problem statement

Captioning after editing is a separate manual step. Re-burning captions on every edit is slow and easy to get wrong, especially when the subtitle file and the video are handled separately.

objectives

  1. Accept a local video and an optional subtitle path.
  2. Find a matching or embedded subtitle track when no path is given.
  3. Apply a caption style, position, and text effect.
  4. Burn the captions without changing the source resolution.
  5. Write the captioned video and its caption files to one output folder.

main features

  1. Local video inputTakes any video path on disk.

  3. Caption stylesViral, Classic, Boxed, Minimal, and Neon.
  4. Position and effectUpper, middle, or lower position with effects such as pop, shake, bounce, fade, word pop, or karaoke.
  5. Resolution preservedBurns captions without cutting or reframing the source.
  6. Caption filesWrites the captioned MP4 plus the ASS and JSON caption files to one folder.
