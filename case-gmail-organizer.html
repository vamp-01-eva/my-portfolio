project overview

A workflow prototype that reads incoming Gmail, asks OpenAI to classify the message, and applies labels based on the content. Priority detection and optional summaries are part of the intended scope.

The organizer is a Make.com workflow that watches Gmail and calls the OpenAI API to classify each message. The classification is used to apply labels and identify promotional or spam-like mail.

The project is an independent prototype. The page describes the intended feature set; each feature should be confirmed against the current build before it is presented as complete.

problem statement

Inbox triage is repetitive. Messages arrive in different categories, and the important ones can get buried under promotions and routine mail.

objectives

  1. Classify incoming email by content and intent.
  2. Apply Gmail labels automatically.
  3. Identify spam and promotional messages.
  4. Surface priority messages.
  5. Optionally generate a short summary.

my role and contributions

Connected Gmail, Make.com, and the OpenAI API in a workflow.

AI-assisted development tools were used for parts of the implementation. I reviewed the generated code, tested the flow, and refined the result rather than treating the output as finished. The feature list is a prototype scope, not a claim that every feature is finished.
